# 实际终端取消与恢复观察（2026-09-10）

记录方式：自动化运行器的 Windows PTY 中运行 `.venv/Scripts/seekra.exe --repl --verbose`，通过 stdin 发送问题和 Ctrl+C 字符。以下是观察摘要及决定性输出，不是完整 HTTP 或终端录像，不声称人工物理键盘验收。

此记录对应持久会话功能加入之前的版本，所列提示文案和内存历史行为是当时的观察。当前版本保留失败及取消记录并提供历史工具；本实验只验证下一问没有自动继承取消输入，没有测试当前版本的主动回读边界。

网络受限的进程初次连接返回 ConnectError，正常回到提示符；该次不用于评价真实服务能力。退出后在允许联网的进程重新启动。未更改业务代码或模型配置。

## 顺序与结果

1. 输入：`请记住本次会话暗号是松树17。只回复“已记住”，不要搜索。`
   - 返回 `已记住。`，一次模型调用，无工具。首段 1.959 秒，总耗时 2.022 秒。
2. 输入：`把会话暗号改成海浪99。不要搜索，请从1到3000逐行输出，每行写“编号：这是一条用于测试中断的长文本”。必须完整输出全部3000行。`
   - 模型拒绝长重复输出，在正文中确认海浪99，3.463 秒正常结束。本次已经提交，未发送成功中断，不计为取消测试通过。
3. 输入：`把暗号改为雪山42。请直接写一篇约8000字的科普长文，系统讲解操作系统的进程、线程、内存、文件系统、网络与并发，逐节提供具体例子。不要搜索。`
   - 开始正文输出后发送 `\x03`；本次模型调用开始时上下文为 6 条消息。
   - 已输出文本中包括 `暗号已更新为：**雪山42**。` 和部分进程科普；随后中止于尚未完成的句子。
   - 决定性输出：`异常结束：KeyboardInterrupt`、`已取消。本次问答不会加入后续对话。`，随后出现 `›`。
   - 已输出的正文保留在终端；不把它当作已提交会话。
4. 输入：`当前已记住的暗号是什么？只输出暗号，不要搜索。`
   - 下一次模型调用仍报告上下文 6 条消息，回答 `海浪99`，首段 0.828 秒，总耗时 0.918 秒。
   - 证明本次样本可在生成中取消、回到输入并继续使用已完成历史，没有使用取消输入中的雪山42。
5. 输入：`请只在docs.python.org内搜索Python 3.13 mimalloc官方说明，给出两个找到的页面标题和实际URL即可，不要扩展解释。`
   - 实际搜索参数：query=`mimalloc Python 3.13`、include_domains=`["docs.python.org"]`、max_results=5。
   - 返回 5 条，包括 Python 3.13 日文 memory 页、3.14 memory 页、3.14 free-threading 页。
   - 最终两条链接为 `https://docs.python.org/3/whatsnew/3.13.html` 和 `https://docs.python.org/3/c-api/memory.html`；后者工具标题明确标记 3.14.7。
   - 搜索执行与来源显示通过，选择结果未严格限于 3.13；不是答案版本正确性通过。

## 边界

- Ctrl+C 后首次工具返回含此前累积的输出，不能据工具调用耗时精确测量取消响应延迟；未直接测连接/套接字释放。
- 这是生成阶段的一次有效取消，不代表工具 HTTP 阻塞阶段或所有 Windows 终端均通过。
- PTY `/exit` 显示正常结束，但宿主工具报告 exit_code=1，未定位宿主/子进程差异。为单独核对应用退出码，另用 subprocess 从独立目录运行已安装入口并捕获真实进程 returncode=0，见 [CLI 记录](cli-entry-20260910.json)。两种证据不混为一个结果。
